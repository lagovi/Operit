# Перевод серверного контента

## Original State

Приложение получает от апстрима два вида пользовательского текста, который не
является ресурсом сборки и поэтому всегда приходит на китайском:

1. **Объявление.** `RemoteAnnouncementRepository` забирает
   `https://operit.app/announcements/latest.json`. Заголовок диалога локализован,
   тело — нет. На устройстве это диалог 公告 с китайским текстом поверх
   английского интерфейса.
2. **Каталог пакетов.** `ArtifactMarketModels` и связанные экраны показывают
   `displayName` и `description` пакетов, которые приходят с рынка. Часть названий
   переведена, часть нет — видно на экране Packages как 楼层限制器 среди
   английских имён.

Ни то, ни другое не проходит через `R.string`, поэтому ни `localeFilters`, ни
`values/`, ни аудит `ci/script/fork_audit.py` на них не влияют. Убирать их из
приложения нельзя: пользователь теряет каталог и объявления.

Сейчас это зафиксировано как известное ограничение форка.

## Intent

Переводить серверный контент на язык приложения на устройстве, с кешированием
перевода, чтобы повторный показ не требовал сети.

## Scope

- Новый слой над существующими вызовами, а не изменение формата на сервере:
  апстрим не наш.
- Кеш в Room, ключ `(url, sha256(тело), targetLang)`.
- Инвалидация по `ts=` — он уже добавляется к запросу
  (`RemoteAnnouncementRepository.addCacheBust`), то есть при смене текста
  меняется и ключ.
- Перевод только при расхождении языков: если в теле нет CJK, отдаём как есть и
  не тратим сеть.
- Язык перевода — `LocaleUtils.currentLanguageCode()`, чтобы добавление русского
  не требовало правок здесь.
- Оффлайн-режим: при недоступной сети показывать последний кеш; при пустом кеше
  и отсутствии сети — исходный текст с пометкой о непереведённом.

## Риски

- Перевод на устройстве требует либо внешнего API-ключа (плохо: это продуктовое
  решение, а не техническое), либо встроенной модели, которую придётся качать
  (тогда нужен UI и учёт места — см. `RemoteAssetFetcher`). Второй вариант
  согласуется отдельно.
- Плагины ToolPkg присылают свой текст через `eventPayload`; там язык
  передаётся флагом `useEnglish`, а не переводом. Не пытаться переводить вывод
  плагинов.
